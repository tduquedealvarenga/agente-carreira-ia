# Privacidade

Este projeto lida com informacoes sensiveis de carreira.

Podem aparecer dados como:

- nome;
- telefone;
- e-mail;
- cidade;
- historico profissional;
- empresas anteriores;
- salarios ou pretensao salarial;
- experiencias pessoais;
- links de perfis publicos;
- documentos enviados pelo usuario.

## Regras Do Produto

- Nao armazenar curriculos reais no repositorio.
- Nao publicar exemplos com dados identificaveis.
- Nao expor prompts internos no repositorio publico.
- Nao colocar chaves de API em codigo, README ou exemplos.
- Usar exemplos ficticios ou anonimizados.

## Direcao De Arquitetura

Prompts e logica sensivel devem ficar no backend ou em repositorio privado.

O frontend publico pode explicar o produto, mas nao deve conter instrucoes internas completas.
