# Roadmap

## Fase 1: Fundacao

- Definir proposta de valor.
- Mapear personas.
- Criar exemplos anonimizados.
- Escrever criterios publicos de qualidade.
- Separar repositorio publico e nucleo privado.

## Fase 2: Prototipo

- Criar fluxo de revisao de curriculo.
- Criar fluxo de coach de LinkedIn.
- Criar fluxo de simulacao de entrevista.
- Testar respostas com casos ficticios.

## Fase 3: Produto

- Criar interface.
- Adicionar upload seguro de documentos.
- Criar historico do usuario com consentimento.
- Adicionar exportacao de sugestoes.

## Fase 4: Validacao

- Coletar feedback de usuarios reais.
- Medir clareza, utilidade e conversao.
- Melhorar criterios de avaliacao.
